# seo-page

Adapted from claude-seo `skills/seo-page`. Single supplied URL.

## Do

1. On-page: title, meta description, H1, canonical, robots, headings, internal links.
2. Content: intent match, thinness, E-E-A-T signals the page actually shows.
3. Technical metadata + images (alt, weight) + schema presence.
4. Use DataForSEO on-page / SERP tools when connected; otherwise inspect the live page in the headed browser.
5. Hand a brief to Content Strategist; do not rewrite the brand story here.
