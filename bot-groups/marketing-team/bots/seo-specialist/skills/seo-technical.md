# seo-technical

Adapted from claude-seo `skills/seo-technical`. No content strategy, no backlink outreach.

## Check

- Crawlability and indexability (robots, sitemap, noindex, canonicals)
- HTTPS / mixed content
- URL hygiene and redirects
- Mobile and Core Web Vitals (LCP, INP, CLS)
- Rendering (JS-only content the crawler may miss)
- Structured data validity (not a full schema rewrite — see a schema ask separately)
- IndexNow / sitemap freshness only if the operator asks

Use DataForSEO on-page / tech endpoints when connected. Flag issues; do not patch the live host without approval.
