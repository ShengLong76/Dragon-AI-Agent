# Cursor skills in this repo

Only the open-source [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) skill is kept (`ui-ux-pro-max`).

Installed with:

```bash
npx ui-ux-pro-max-cli init --ai cursor
```

The CLI also unpacks paid brand/logo extras (`brand`, `design`, `banner-design`, …). Those are not vendored here.
