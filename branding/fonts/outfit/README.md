# Outfit — Dragon AI Agent UI face

**Family:** Outfit  
**License:** SIL Open Font License 1.1 (`OFL.txt`)  
**Authors:** The Outfit Project Authors — https://github.com/Outfitio/Outfit-Fonts

Tesla’s car and site type is **Universal Sans** (proprietary). This package does **not** vendor that font and does not claim to ship it.

Outfit is a free geometric grotesque in the Gotham / Universal Sans neighborhood: even stroke, high x-height, simple terminals, drawn for digital UI. It reads modern on the empty-state wordmark and stays legible in the composer and settings chrome. Montserrat is the usual Gotham stand-in; Outfit is the more current UI cut of the same idea.

Latin `woff2` files are bundled here so UltraDragon does not need the font installed. The launch overlay copies them into the unpacked Electron renderer and injects `dragon-ui.css`.
